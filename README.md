## Current flagship project

### [AiRC Orchestration — Beta](https://github.com/AiRC-ai/AiRC-Orchestration)

A desktop AI orchestration platform for persistent, project-scoped work. AiRC keeps tasks, model state, capabilities, goals, plans, and execution evidence together—then lets you combine hosted, local, or remote models with tools, extensions, skills, recipes, apps, automations, bounded subagents, and optional Orchestrator session coordination.
