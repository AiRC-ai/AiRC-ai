## Current flagship project

### [AiRC Orchestration — Beta](https://github.com/AiRC-ai/AiRC-Orchestration)

A desktop AI orchestration platform for work that outlasts a single prompt. AiRC keeps tasks, model state, capabilities, goals, plans, and execution evidence connected — so you can combine hosted, local, or remote models with tools, extensions, skills, recipes, apps, automations, subagents, and optional Orchestrator session coordination.
